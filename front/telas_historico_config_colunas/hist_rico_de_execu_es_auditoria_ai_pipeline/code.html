# 🚀 Pull Request: Sugestão de Filmes com Filtro de Streaming, Cache de Rejeitados (FIFO 30) e Modelo Gemini 3.5 Flash
## 📝 Descrição da Intervenção

### Contexto & Problema:
O subsistema de sugestão com IA para filmes apresentava três limitações principais relatadas pelos usuários:
1. Recomendação de obras fora de catálogo streaming.
2. Repetição de filmes rejeitados (sem histórico em cache FIFO).
3. Repertório limitado via modelo anterior.

### Solução Arquitetural Implementada ([Agente Arquiteto + Dev]):

1. Atualização do modelo padrão no OpenRouter para google/gemini-3.5-flash em services.php.
2. Filtro Multi-seleção de Serviços de Streaming integrado ao frontend Vue e validado em GenerateSuggestionRequest.php.
3. Cache local de exclusão preventiva ativado com TTL de 48h.
